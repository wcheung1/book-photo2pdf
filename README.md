# 書影 BookScan

用手機或者電腦影實體書，自動搵書邊、切開左右兩頁、拉直彎曲嘅頁面，再砌成一本 PDF。

**私隱：** 所有相片只會存喺你自己部機嘅瀏覽器入面處理，唔會上傳去任何伺服器。網頁第一次打開時，會由網上下載 AI 運算庫同模型（呢啲係程式，唔係你嘅相），之後會留喺瀏覽器快取。

---

## 一、放上 GitHub（只用瀏覽器，唔使識 git）

1. 登入 [github.com](https://github.com)，撳右上角 **＋ → New repository**。
   - Repository name：例如 `bookscan`
   - 揀 **Public**（免費帳戶要 Public 先開到 GitHub Pages。公開嘅只係程式碼，你嘅相永遠唔會喺度）
   - 撳 **Create repository**
2. 喺新 repo 頁面撳 **uploading an existing file**（或者 **Add file → Upload files**）。
3. 將解壓之後**資料夾入面所有嘢**（`index.html`、`app.js`、`vision.js`、`README.md`、`models` 資料夾、`training` 資料夾等）一次過拖入去個網頁。
   - 一定要拖埋 `models` 資料夾，入面有 AI 模型（最大嗰個約 16 MB，低過 GitHub 網頁上載 25 MB 嘅上限）。
   - 用 Chrome 或者 Edge 拖資料夾最穩陣。
4. 等佢上載完，撳綠色 **Commit changes**。
5. 去 repo 嘅 **Settings → Pages**：
   - Source 揀 **Deploy from a branch**
   - Branch 揀 **main**，資料夾揀 **/ (root)**，撳 **Save**
6. 等一兩分鐘，重新整理 Settings → Pages，上面會出現網址，例如 `https://你的帳戶名.github.io/bookscan/`。用手機或者電腦打開就用得。
   - 手機可以喺瀏覽器選單揀「加到主畫面」，用起嚟似個 app，資料亦冇咁易被瀏覽器清走。

> **更新程式：** 之後我改咗檔案，你只要再做第 2–4 步，上載同名檔案覆蓋就得。

---

## 二、點樣用

1. 撳 **＋ 新書**，揀 **橫排（向左翻）** 或者 **直排（向右翻）**。
2. 兩個方法加相：
   - **影相**：開相機，有對準框同即時提示（框變綠就係已對準）。電腦可以撳空白鍵影。
   - **上載相片**：一次揀晒已經影好嘅相（電腦可以直接拖相入去）。會按相片嘅拍攝時間排好；冇拍攝時間就按檔名。
3. 程式會自動：搵書邊同四隻角 → 判斷係單頁定跨頁 → 搵書脊切開左右 → 用 AI 拉直彎曲嘅頁。
4. 檢查每一張：
   - 撳縮圖或者 **調整**：可以拖角點、拖四條邊（拖邊中間嘅白點或者條線）、拖書脊。拖嘅時候有**放大鏡**，會自動放喺離你手指最遠嘅角落。兩指或者滑鼠滾輪可以放大縮細。
   - 唔應該切開嘅（封面、單頁）：撳 **單頁**；應該切開嘅撳 **跨頁**。
   - 跨頁入面唔要某一頁（例如空白頁）：撳 **左頁 / 右頁** 剔走。
   - 偵測唔到書：會用成幅相（唔會變灰色或者四點擠埋一齊），撳 **自動偵測** 再試，或者手動拉。
   - **預覽**：睇最後效果。
   - 影得唔好：撳 **重影**，新相會取代原位。
   - 次序亂咗：用卡片左上角 **⠿** 拖動；或者 **設定 → 按拍攝時間／按檔名**。
   - 揀多張（右上角剔格）可以一次過刪除或者設為單頁／跨頁。
5. **匯出 PDF**：
   - **每頁高度（厘米）**：只影響打印出嚟幾大，同閱讀器「100%」時幾大。預設 21 厘米（一般書嘅大細）。
   - **解像度**：標準 2400 像素高（21 厘米時約 290 dpi），睇字好清楚。唔會放大超過原相。
   - 每頁闊度跟返嗰頁自己嘅比例，唔會拉長或者壓扁。直排書嘅 PDF 會設定成由右至左閱讀。

## 三、儲存空間同刪除

- 相片存喺瀏覽器嘅「網站資料」（IndexedDB）入面，**喺檔案管理或者相簿度係搵唔到嘅**。
- 要釋放空間：喺 **書架** 逐本書撳 **刪除**；書架底部有 **儲存空間** 一欄，顯示用咗幾多。
- 或者去瀏覽器設定 → 網站資料／Cookies → 搵呢個網址 → 刪除（會刪晒所有書）。
- 建議：匯出 PDF、確認冇問題之後，就刪除嗰本書。

---

## 四、GPU 同速度

- 曲頁拉直用 AI 模型（UVDoc）。瀏覽器支援 WebGPU 就會用你部機嘅 GPU，快好多；唔支援就自動用 CPU，每頁大約一至幾秒。
- 狀態欄會顯示「曲頁拉直用 GPU（WebGPU）」或者「CPU（WASM）」。
- 唔需要任何 API、唔使收費。

---

## 五、令偵測更準：用你自己嘅相微調（可選）

1. 用一排之後（愈多愈好，建議 100 張以上），喺書本頁面 **設定 → 匯出訓練資料（zip）**。你手動調整過嘅角點會用嚟教個模型。
2. 跟 `training/README.md` 喺電腦（有 NVIDIA 顯示卡最好）執行微調。
3. 佢會輸出新模型檔同更新 `models/manifest.json`。將呢兩個檔案上載去 GitHub repo 嘅 `models` 資料夾覆蓋舊嘅就得。

## 六、檔案

| 檔案 | 用途 |
|---|---|
| `index.html` | 網頁本身 |
| `app.js` | 介面、儲存、相機、匯出 PDF |
| `vision.js` | 搵書邊、書脊、拉直、輸出每一頁 |
| `models/doccornernet_lean.onnx` | 搵書四隻角嘅 AI 模型（1.8 MB） |
| `models/uvdoc.onnx` | 拉直曲頁嘅 AI 模型（16 MB） |
| `models/manifest.json` | 指定用邊個模型檔 |
| `training/` | 喺電腦微調模型用（唔影響網頁） |

第三方開源元件見 `THIRD_PARTY_NOTICES.md`。
